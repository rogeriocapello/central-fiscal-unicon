# Central Fiscal Unicon

Sistema web para centralização da operação fiscal da Unicon.

## Escopo inicial
- Clientes e CNPJs
- Certificados digitais com armazenamento seguro
- Documentos fiscais/XML
- Obrigações e pendências
- Integrações Domínio, SIEG e SEFAZ
- Auditoria
